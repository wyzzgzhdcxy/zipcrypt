# ZipCrypt · 快速归档加密

Wails 3 + Vue 3 的 Windows 桌面小工具：选一个文件夹，点一下，打成 **AES 加密的 7z**，
可选择把下面的子文件夹分别打成独立加密包，带实时进度、结果列表和"打开加密文件所在目录"按钮。

核心就是这一条命令（其余开关只影响输出和安全性，不改变归档内容）：

```
7z a -mx0 -p"<密码>" -mhe=on <输出>.7z .\<源文件夹>
```

- `-mx0` 只存储不压缩 → 最快，基本等于磁盘读速
- `-mhe=on` 连文件头一起加密 → 不带密码连文件名都看不到
- 附加开关：`-bsp1` 进度重定向到 stdout、`-bb0` 精简日志、`-y` 自动覆盖、
  `-sccUTF-8` 让中文路径按 UTF-8 输出、输出目录落在源目录内时自动加 `-x!<包名>` 防止把压缩包打进自己

## 功能

| 功能 | 说明 |
| --- | --- |
| 选目录 | 系统目录选择框，也可以直接粘贴路径，边输入边统计文件数/大小/子目录 |
| 加密 | 一键执行上面那条命令，密码默认 `wangchaojun`（可改，记在本机配置里） |
| 实时进度 | 进度条 + 已写字节 / 总字节 + 实时速度 + 7z 原始输出日志 |
| 打开所在目录 | 一键打开输出目录并选中刚生成的压缩包；结果列表里每个包也能单独打开 |
| 归档子目录到单独文件 | 开关式选项。**关闭**：所选文件夹整体打成一个包（包内保留原文件夹名）。**开启**：不加密所选文件夹本身，而是把它下面的**每个子文件夹各自打成一个独立加密包**，根目录散落文件合成一个包 |
| 取消 | 中途可取消，本次新建的半成品压缩包会被自动清理 |
| 删除源文件 | 默认关闭；开启需二次确认，删除清单写入 `%APPDATA%\ZipCrypt\removed-*.log` 便于事后核对 |
| 覆盖同名包 | 默认勾选（对应 `-y`）；取消勾选时遇到同名包会明确报错而不是静默覆盖 |

### 两种模式的产物对比

源目录 `D:\videos\合集`，里面是 `动画\`、`漫画\`、`说明.txt`：

| | 输出目录 | 产物 |
| --- | --- | --- |
| 关闭拆分 | `D:\videos` | `合集.7z`（内含 `合集\动画\...`、`合集\漫画\...`） |
| 开启拆分 | `D:\videos` | `动画.7z`、`漫画.7z`、`根目录文件.7z`（各自独立加密） |

开启拆分时，"文件名"输入框变成**前缀**：填 `jp_ry` 得到 `jp_ry-动画.7z`、`jp_ry-漫画.7z`；留空则直接用子目录名。

> 输出目录默认是源文件夹的**上一级**，这样压缩包不会落进被归档的目录里。
> 就算手动选了源目录本身，程序也会自动加 `-x!` 把压缩包自己排除掉。

## 构建

```powershell
.\script\build.ps1
```

脚本会依次跑 `go vet` → `go test` → `wails3 build` → 结束正在运行的 `zipcrypt.exe`
→ 把 `bin\zipcrypt.exe` 复制到 `D:\app_mgr\my\`。

只想构建不部署：

```powershell
wails3 build
```

开发模式（前端热更新）：

```powershell
wails3 dev
```

环境要求：Go 1.25+、Node 20+、wails3 CLI（`go install github.com/wailsapp/wails/v3/cmd/wails3@latest`）、
以及本机装了 7-Zip（程序会自动探测 `7z.exe` / `7zz.exe`，找不到时界面右上角会报错并可手动指定路径）。

## 测试

单元测试（不碰 7z，秒级）：

```powershell
go vet ./...
go test ./...
```

真实 7z 端到端用例（默认跳过，只在临时目录造数据并往临时目录解压）：

```powershell
$env:ZIPCRYPT_LIVE = '1'
go test ./internal/archive/ -run Live -v
```

覆盖：整包结构（包内是 `合集\...` 而不是整条磁盘路径）、解压后逐字节比对、
错误密码必须解不开、拆分模式各包不串内容、输出目录等于源目录时不自包含、
按压缩包体积换算的进度确实在涨。


## 几个实现上的坑（已处理）

- **7-Zip 23+ 在非 TTY 环境下不再逐文件打印进度**（实测 26.03 只输出一行 `0%`）。
  这里的进度改为轮询压缩包体积换算：`-mx0` 是纯存储，包体增长几乎线性，效果比解析日志稳。
  逐条进度行的解析器仍然保留，兼容老版本 7-Zip。
- **工作目录决定包内结构**。7z 按"相对当前目录"存路径，所以整体打包时把工作目录设成
  源目录的上一级、传 `.\源文件夹`，包内就只有 `源文件夹\...`，解压不会带出一整条 D 盘路径。
- **密码不能为空**。`-p` 不带值时 7z 会转去读控制台要密码，GUI 里必然卡死，程序提前拦掉。
- **取消 / 失败不留半成品**。本次新建的压缩包会被删掉；覆盖模式下原有的包不删（可能是你的旧文件）。

## 已知取舍

- 密码按需求明文存在 `%APPDATA%\ZipCrypt\settings.json`，且以命令行参数传给 7z
  （同机其他进程可在任务管理器里看到）。这是需求里指定的行为，要更稳妥可以改成走环境变量或管道。
- "删除源文件"是硬删除，不进回收站。之所以加删除清单日志，是为了事后能核对到底删了什么。
